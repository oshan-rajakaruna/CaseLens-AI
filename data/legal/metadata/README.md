# Legal dataset manifests

Store reviewed JSON manifests here. Copy `manifest.template.json` to
`manifest.json` before adding manually reviewed records. The empty template is
for the future curated dataset; it does not assert that any documents have
already been collected.

`manifest.example.json` demonstrates every supported field but is disabled,
contains no legal text, and is not real case law. Never relabel synthetic or
example content as a real legal source. Follow
`docs/LEGAL_DATASET_COLLECTION.md` before enabling an entry.
