# Local legal source documents

Place approved, curated UTF-8 `.txt` source files here for local ingestion. The
directory contents are ignored by Git except for this guidance and `.gitkeep`.
Do not commit confidential, copyrighted, or unreviewed source material.

PDF and OCR ingestion are not supported in Retrieval Milestone 6. Convert only
material that the team is authorized to use, retain its provenance, and review
the converted text before ingestion.
