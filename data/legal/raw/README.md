# Local legal source documents

Place approved, curated UTF-8 `.txt` files and embedded-text `.pdf` files here
for local ingestion. The directory contents are ignored by Git except for this
guidance and `.gitkeep`. Do not commit confidential, copyrighted, or unreviewed
source material.

PDF extraction reads textual page content only. Scanned or image-only PDFs need
OCR, which is not supported in the current MVP. Do not assume every PDF is
extractable. Use only material that the team is authorized to use, retain its
source and provenance, and review extracted text before relying on retrieval.
