# Evaluation data

This location is reserved for future reviewed retrieval judgements tied to a
curated legal dataset. The current offline framework fixture remains under
`tests/evaluation/` because it is explicitly synthetic test data.

After the curated dataset exists, the team will create reviewed queries and
relevance judgments here, then compare BM25, semantic, and hybrid retrieval
with Precision@K, Recall@K, and MRR. No synthetic framework result is a final
real-dataset evaluation score.
