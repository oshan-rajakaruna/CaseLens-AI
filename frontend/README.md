# CaseLens frontend

This directory contains the minimal React and Vite application shell for Phase
1. It intentionally has no routing library, component framework, authentication
flow, or final product pages.

## Run locally

```powershell
npm install
npm run dev
```

Set `VITE_API_BASE_URL` in the repository `.env` when the backend is not
available at `http://127.0.0.1:8000`.
